# SacredBaboons
This is the repo in which we store the code and data for our work on Thoth and sacred baboons. The three files contain information on the Papio samples measured at the ANMH (Papio spectra AMNH), adn the processed spectral data for the baboons (Pelage_processed_spectra) and for the ibis (Plumage_processed_spectra).
